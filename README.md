# 🧪 Example

## Input

```text
image1.png
image2.png
image3.png
```

## Output

```text
image1.png -> renamed_1.png
image2.png -> renamed_2.png
image3.png -> renamed_3.png
```

# 🚀 Running

## JavaScript

```bash
node renamer.js
```

## Python

```bash
python renamer.py
```

## C#

```bash
dotnet run
```
